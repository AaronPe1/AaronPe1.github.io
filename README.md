## 首次发布

1. 在自己的 GitHub 账号 AaronPe1 下创建公开仓库 AaronPe1.github.io。
2. 将本目录的**内容**上传到仓库根目录：index.html 直接位于根目录，assets/ 保持为子目录。不要只上传 ZIP 文件。
3. 打开 Settings → Pages，选择 Deploy from a branch，分支 main、目录 / (root)，保存。
4. 等待 GitHub Pages 部署成功，再访问上方地址。访客无须登录。
